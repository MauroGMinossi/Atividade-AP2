Atividade: Sistema de Gerenciamento de Funcionários e Folha de Pagamento

Projeto desenvolvido em Java aplicando os conceitos de Programação Orientada a Objetos (POO), arquitetura em camadas, exceções personalizadas e testes unitários com TDD e JUnit 5.

Principais funcionalidades:

Cadastro de Funcionários
Listagem de todos os funcionários
Busca de funcionário por código, CPF ou nome
Exclusão de cadastrado
Cálculo individual de salários e tributos
Exibição dos dados completos
Geração de relatório da folha de pagamento
Cálculo do valor total da folha de pagamento da empresa
O sistema está estruturado em camadas e utiliza armazenamento em memória.
